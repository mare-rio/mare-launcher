A quieter home for your TV.

This folder contains Maré Launcher and everything needed to start its guided setup. Keep this page open while you prepare your TV.

For TCL Android TV and Google TV, and compatible Android TVs from other brands, running Android 8 or newer. TCL Roku TVs cannot install Android apps.

1. Get your computer ready

Connect your computer and TV to the same home network. Wi-Fi or Ethernet both work. Keep the TV awake and the remote nearby.

The installer needs Python 3.9 or newer. If you do not have it, download Python for your computer and complete its installer first. On Windows, the Python install manager will guide you through installing Python 3; if using the traditional installer, tick Add python.exe to PATH. No coding or Python packages are needed.

2. Prepare your TCL TV

  1. Open Settings → System → About. On some TVs it is Settings → Device Preferences → About.
  2. Find Android TV OS build or Build number. Press OK on it seven times, until the TV says developer mode is enabled.
  3. Go back and open Developer options. Turn on Network debugging or ADB debugging. Some TCL models call this USB debugging. If yours instead has Wireless debugging, enable that.
  4. Find the TV’s IP address under Network → your connection or About → Status. Leave the TV on; you will enter that address during setup.

If Wireless debugging offers a pairing code, setup will walk you through both addresses and the code. If your TV has no way to enable network debugging, see connection help. Menu names vary by TCL model. Leave OEM unlocking alone; it is not needed.

3. Start setup on your computer

Use the files in the extracted folder, not inside the unopened ZIP.

Windows

Double-click install.cmd. A setup window opens. Choose 1 — Install or update Maré, or press Enter.

Mac
  1. Open the Terminal app using Spotlight.
  2. Type sh followed by a space. Drag install.command from this folder into the Terminal window, then press Return.
  3. Choose 1 — Install or update Maré, or press Return.
Linux

Open a terminal in this folder and run sh install.sh. Choose 1 — Install or update Maré, or press Enter.

  1. Follow the prompts. Type y for yes, or press Enter for no. Enter your TV’s IP address when asked.
  2. Setup can download Google’s connection tool, ADB. If asked, read and accept Google’s licence to continue.
  3. Watch the TV for Allow debugging? and accept it with your remote.
  4. Check that setup displays your TV model, then answer y to install. If it asks to turn off Google Home so Maré can open instead, answer y to make Maré your Home screen.

Your streaming apps and their settings stay in place. Setup keeps a recovery record on this computer so you can bring the old Home screen back.

4. Make it yours

Press Home on the TV remote. In Maré, open Apps, hold OK on an app and choose Pin to home. Repeat for your favourites. On a slower TV, try Settings → Motion → Off.

Turn debugging off in the TV’s Developer options when finished. Your computer can now disconnect. Restart the TV normally to check that Home still opens Maré.

Updates and going back

For updates, download the latest installer ZIP and choose 1 again. Your favourites stay. To go back, enable debugging, run setup on the same computer and choose 2 — Restore my previous Home screen. Option 3 also removes Maré. Keep the recovery file whose location setup prints.
